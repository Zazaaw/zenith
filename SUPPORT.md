# Support

Zenith is a personal project by [Satu Visual](https://github.com/satuvisual), looked
after on a best-effort basis. There is no support contract and no promised response
time.

Most questions are answered by the [troubleshooting guide](docs/TROUBLESHOOTING.md).

## Report a bug or request a feature

Open an issue on [satuvisual/zenith](https://github.com/satuvisual/zenith/issues/new/choose).
For a bug, include the Zenith version and build from Settings under About, your macOS
version and the steps that reproduce it.

## Report a security issue

Keep vulnerabilities out of public issues. The [security policy](SECURITY.md) explains
how to report them privately.
